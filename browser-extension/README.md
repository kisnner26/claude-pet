# web scout

extensión local para chromium. claude o codex marcan la selección actual con patas visuales y revisan nombres accesibles, `alt`, objetivos táctiles, ids duplicados, desbordes y contraste del dom visible.

## instalar

1. abre `chrome://extensions` o `edge://extensions`.
2. activa el modo desarrollador.
3. usa **cargar descomprimida** y elige esta carpeta.

no usa red, no guarda contenido y solo se inyecta en la pestaña cuando pulsas un comando. las flechas recorren hallazgos y `esc` elimina las marcas.
